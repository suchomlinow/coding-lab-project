# coding-lab-project
Coding Lab Project files

## Project: Chicago's 2026 Budget Revenue

Course project for PPHA 30110, Autumn 2026.

Policy question: Which local funds have the largest estimated revenue in Chicago's 2026 budget ordinance?

## Folders

- `data/`: downloaded CSV data, kept unchanged.
- `code/`: R scripts as the analysis develops.
- `assignments/`: assignment write-ups.

## Data

[Budget - 2026 Budget Ordinance - Revenue](https://data.cityofchicago.org/Administration-Finance/Budget-2026-Budget-Ordinance-Revenue/nydj-5nax/about_data), published on the City of Chicago Data Portal.

Downloaded October 10, 2026: `data/Budget_-_2026_Budget_Ordinance_-_Revenue_20261010.csv`.

The downloaded file contains 156 rows and 6 columns. Revenue figures are budget estimates, not actual collections.

See [Assignment 1](assignments/a1-proposal.md) for the data description, planned variables, and initial checks.
